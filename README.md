# Jade Schembri — Portfolio

Personal portfolio of Jade Schembri, AI Evaluation & Data Specialist based in Malta.

- `index.html`: the portfolio page (single file, no build step)
- `Jade_Schembri_Resume.pdf`: résumé, embedded and downloadable from the page
- `logos/`: company, university and certification logos used on the page

To view it, open `index.html` in a browser or enable GitHub Pages for this repository (Settings → Pages → Deploy from branch `main`, folder `/`).
